# Stage 14：B 有效证据并入 C 的诊断

## 目的

检查删除独立 B Actor 后，哪些几何证据值得保留为 C 的按需工具，以及这种拆解是否仍符合多智能体定义。

本诊断使用测试轨迹标签进行五折交叉验证，只用于判断信息潜力，不是部署模型，也不作为正式泛化结果。

## 结果

| 证据组合 | 诊断 AUROC | 诊断 OSCR |
|---|---:|---:|
| Boundary + A 报告 | 95.80% | 95.18% |
| Boundary + A + 融合几何报告 | 98.28% | 97.50% |
| 完整 ABC 参考 | 98.61% | 97.80% |

融合后与 ABC 相差约 0.3 个百分点。用户接受这个差距，因此最终框架采用 A+C：删除 B Actor，把有效几何感知保留为 C 的工具。

单项证据诊断：

| B 证据 | 无方向 AUC | Known 均值 | Unknown 均值 |
|---|---:|---:|---:|
| 几何原型风险 | **98.51%** | 0.5032 | 0.9837 |
| 几何置信度 | 91.46% | 0.9858 | 0.8418 |
| 几何间隔 | 86.87% | 0.9268 | 0.6700 |
| SUPPORT / CHALLENGE 离散动作 | 50.00% | 常量 | 常量 |

## 架构解释

- 几何 backbone、原型表和风险计算器是冻结感知工具，不是隐藏智能体；
- C 必须显式执行工具动作并支付工具预算后才能读取几何风险；
- A、C 仍有独立 Actor、私有观测、动作空间、循环状态和结构化通信；
- C 的终局裁决对工具打乱干预敏感，因此工具证据真实进入了决策；
- SUPPORT/CHALLENGE 没有独立信息，不再为其保留 B Actor。
