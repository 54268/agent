# Codex任务指令：多智能体开放集辐射源识别

请在本机完成一个**多智能体开放集辐射源识别（Multi-Agent Open-Set SEI）**原型项目，重点不是简单把网络模块改名为Agent，而是设计“多个专家Agent + 动态路由/协同决策”来完成已知辐射源分类和未知辐射源拒识。

## 任务
1. 先阅读两个参考目录中的网络、损失函数、开放集判别、数据预处理与评估代码，总结哪些模块可以借鉴，哪些不能直接复用为创新点。
2. 检查WiSig数据结构、样本格式、Tx/Rx/日期等字段，建立可复现的数据读取、训练/验证/测试与开放集划分流程。
3. 设计新的多智能体OS-SEI框架，优先考虑：
   - **Emitter/Fingerprint Expert**：学习发射机硬件指纹；
   - **Channel/Domain Expert**：学习跨接收机、跨日期鲁棒特征；
   - **Open-Set Expert**：基于原型距离、能量/不确定性等建模未知空间；
   - **Dynamic Router**：根据样本特征、置信度、距离或域信息动态分配各Agent权重；
   - **Fusion/Decision Agent**：融合专家证据，输出已知类别或Unknown。
4. 动态路由必须真正影响推理，不要只做固定加权；保留每个Agent的独立输出，方便后续做消融实验和可解释性分析。
5. 不要直接照搬MFE-Net、现有开放集网络或参考目录中的完整结构；可以借鉴基础模块，但新的核心创新应放在**专家分工、Agent通信/协同、动态路由以及开放集决策机制**上。
6. 先实现一个可训练、可复现的最小版本，再逐步增加复杂度。建议至少包含：
   - closed-set baseline；
   - single open-set baseline；
   - multi-agent without router；
   - multi-agent + dynamic router（最终模型）。
7. 评估至少包括：Known Accuracy、Unknown Recall、Macro-F1、AUROC/OSCR（若方便实现），并保存混淆矩阵、路由权重分布和各Agent消融结果。
8. 代码写到新的项目目录中，不要污染参考代码。目录结构清晰，提供`README.md`、配置文件、训练脚本、测试脚本和结果输出目录。

## 先做什么
先不要急着大改网络。第一步请完成：
- WiSig数据审计；

- 然后再开始编码。

最终目标是形成一个可以继续写论文的方法原型，而不是简单复现现有算法。
