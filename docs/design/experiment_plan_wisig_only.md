# WiSig-only 充分实验计划

## 1. 决策摘要

本项目不再把 28 类均衡核心集作为论文主实验。它只用于数据管线、损失和指标的快速验证。论文主结果使用 WiSig 的全部 174 个发射机，并以 `120 Known + 54 Unknown`、跨日期和跨接收机联合迁移作为默认任务。

只使用一个数据集并不等于只做一个划分。说服力来自五条相互独立的证据链：

1. 类别规模从 50 增加到 174；
2. Unknown 比例从 34 类增加到 114 类；
3. IID、跨日期、跨接收机、联合迁移逐级加难；
4. 少样本、噪声、接收机分组和日期折叠压力测试；
5. 多智能体通信、路由和每个 Agent 的严格反事实消融。

## 2. 经过数据审计支持的规模层级

固定 P3 域划分后，对每个 Tx 分别计算 train/validation/test 的聚合包数，得到：

| 层级 | 入选规则：三个 split 的每类包数均不少于 | 实际 Tx 数 | 默认 Known / Unknown | 用途 |
|---|---:|---:|---:|---|
| C50 | 1600 | 50 | 35 / 15 | 高密度、低方差对照 |
| C87 | 800 | 87 | 60 / 27 | 中规模对照 |
| C143 | 400 | 143 | 100 / 43 | 大规模均衡对照 |
| C152 | 200 | 152 | 106 / 46 | **主要受控规模实验** |
| C158 | 100 | 158 | 110 / 48 | 稀疏性过渡 |
| F174 | 1 | 174 | 120 / 54 | **全部类别主实验** |

F174 中每类最少包数为 train=362、validation=48、test=110，所有类别在三个 split 都非空。训练使用 class-aware/domain-aware sampler，评价同时给出 macro 指标与每类结果，避免高频 Tx 主导结论。

资格集合由支持度规则自动生成；对排序后的合格 Tx 使用固定 seed 打乱。前 K 类为 Known，其余为 Unknown。实现时必须将最终实体列表写入每次运行目录，不能只保存 seed。

## 3. 固定域划分

只使用四个日期都存在的 30 个 Rx。seed=42 的主划分如下：

- train Rx（20）：`8-8, 20-20, 18-19, 3-2, 3-19, 24-16, 13-7, 24-13, 7-7, 19-19, 23-5, 23-7, 19-1, 14-14, 23-3, 13-13, 1-1, 20-19, 23-1, 24-5`
- validation Rx（5）：`19-20, 19-2, 20-1, 8-7, 11-10`
- test Rx（5）：`13-14, 8-14, 1-19, 2-19, 18-2`
- train dates：`2021_03_01, 2021_03_08`
- validation date：`2021_03_15`
- test date：`2021_03_23`

接收机和日期必须按组划分，禁止将同一 `(Tx, Rx, date)` 的包随机拆到训练与测试两侧。

## 4. 协议矩阵

### 4.1 四个难度协议

| 协议 | 日期变化 | Rx 变化 | Unknown Tx | 定位 |
|---|---:|---:|---:|---|
| P0 | 否 | 否 | 是 | 冒烟和旧结果对齐，不支撑主结论 |
| P1 | 是 | 否 | 是 | 分离日期漂移 |
| P2 | 否 | 是 | 是 | 分离接收机偏移 |
| P3 | 是 | 是 | 是 | **论文主协议** |

### 4.2 类别规模实验

在 P3 下依次运行 C50、C87、C143、C152、C158、F174。完整模型至少与 B1 单 Agent、B2 无消息多 Agent、MEDAF 和最强跨域开放集基线比较。报告性能随类别数变化的斜率，而不只报告单点最好值。

### 4.3 开放程度实验

固定 174 类全集和同一类别排列，运行：

| Known / Unknown | Openness `1-sqrt(2K/(2K+U))` |
|---:|---:|
| 140 / 34 | 0.0557 |
| 120 / 54 | 0.0965 |
| 100 / 74 | 0.1456 |
| 80 / 94 | 0.2063 |
| 60 / 114 | 0.2839 |

主文至少展示 AUROC、OSCR、Known Accuracy 和 Unknown F1 随 openness 的曲线。

### 4.4 域泛化补充实验

- Leave-one-date-out：四个日期分别作为测试日；其余日期中一个作验证、两个作训练。
- Receiver 6-fold：30 个公共 Rx 分为 6 组，每次 1 组测试、1 组验证、4 组训练。
- 联合协议仍以固定 P3 为主；完整的 4×6 联合网格只运行 B1、最强外部基线和完整模型，控制计算量。
- 报告每个 Rx、每个日期及 worst-group 指标，不能只给总体平均值。

### 4.5 数据量和鲁棒性

- Few-shot：每个 Known Tx 使用 5、10、20、50、100、300 个训练包。
- 合成 AWGN：`-10, -5, 0, 5, 10, 20 dB, clean`。训练增强与纯测试扰动分开报告。
- 相位旋转、幅度缩放、有限时间平移和小 CFO 作为补充 nuisance stress；每个变换单独开关，避免无法解释的组合增强。
- 报告 Router 在噪声等级、Rx 和日期变化下的权重、稀疏边数、熵和 Agent 使用率是否发生有意义的变化。

## 5. 公平的数据使用规则

1. 真实 Unknown Tx 不参与训练、验证、早停、阈值搜索或超参数选择。
2. Unknown 监督仅来自 Known 类 leave-class-out episode、边界伪未知和特征扰动伪未知。
3. 所有方法使用完全相同的 manifest、归一化、数据增强预算和选模准则。
4. OpenRFI 等依赖未标注开放世界数据的方法必须放在“额外未标注数据可用”轨道，不能与纯监督 OSR 混为一表。
5. 类别不均衡时使用 class-aware sampler；评价使用 macro-F1、macro per-class AUROC，并同时公开 micro 结果。
6. OSCR 必须使用拒识前的闭集预测计算，不能使用拒识后的标签回填。

## 6. 模型与基线层级

### 6.1 核心内部对照

- B0：closed CVCNN + MSP。
- B1：单 Agent，Energy + Prototype distance。
- B2：时间/频相/域/开放集 Agent 独立工作，均匀 late fusion，无消息。
- B3：固定全连接消息 + 均匀 fusion。
- B4：动态权重但删除消息状态更新，用来区分 Router 与普通 gating。
- B5：动态稀疏图、显式消息、可靠性估计、反事实信用分配的完整 MAROS-SEI。

### 6.2 强外部基线

- 公共 OSR：MSP、Energy、ODIN、OpenMax、ARPL、OpenOOD 中可公平迁移的 post-hoc 方法。
- 多专家 OSR：MEDAF。
- 本地 OS-SEI：PCBM、HyperRSI、HyDRA、MFE-Net 可重跑部分。
- 近年 RF：OpenRFI、动态边界 OS-SEI、OFSCIL、DM-MML。
- 跨接收机：Receiver-Agnostic RFFI、IB-RFF、ASKNet；给它们连接完全相同的 open-set head，分离 backbone 与拒识器贡献。

不能直接运行的工作应写清“官方实现适配”“依据论文重实现”或“仅设计借鉴”，不得统一写成官方复现。

## 7. 证明多智能体而不是多分支

完整模型必须满足：

1. 每个 Agent 有不同观察、私有编码器、局部分类/不确定性输出和局部损失；
2. Router 输出样本相关的有向稀疏通信图，而不只是最终融合权重；
3. Agent 接收消息后通过 GRU/残差更新产生 `pre-message` 与 `post-message` 两套输出；
4. 每条消息携带内容向量和可靠性，Receiver 根据边权决定是否接收；
5. Fusion Agent 使用更新后的证据做 known/unknown 联合决策；
6. 有通信预算、Agent 多样性和近似反事实边际贡献损失；
7. 保存逐样本图、权重、消息范数、可靠性和局部预测。

必须做的反事实实验：权重打乱、发送者打乱、删除消息、固定均值路由、Agent dropout、逐 Agent 移除、soft/hard top-k、不同通信轮数、删除信用损失、删除预算损失。

## 8. 统计报告

- 核心 B0/B1/B2/B5：3 个类别 seed（13/42/87）× 3 个训练 seed（0/1/2）。
- 强基线：固定类别 seed=42，至少 3 个训练 seed；主表赢家再补齐三个类别 seed。
- 消融：固定类别 seed=42，3 个训练 seed。
- 主指标给均值、标准差和 95% 分组 bootstrap CI；重采样单位优先为 Tx，再在 Tx 内按 Rx/date 分组，禁止把相关的 packet 当独立样本夸大显著性。
- 比较完整模型与最强基线时报告配对差值和效应量，不只报告 p 值。

## 9. 运行产物约定

每个 `results/runs/<run_id>/` 必须包含：

- 完整解析后的配置、git commit、环境与随机种子；
- 实体化的 Tx/Rx/date manifest 及源文件校验信息；
- best/last checkpoint 与选模指标；
- packet 级预测、pre/post-message Agent 输出和 unknown score；
- Router 图、权重、消息可靠性、通信成本；
- overall、per-class、per-Rx、per-date、worst-group 指标；
- 混淆矩阵、ROC/PR/OSCR、可靠性图和路由可解释图。

根目录 `总结果汇总.md` 只能由这些可追溯产物更新。
