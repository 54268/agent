# Stage-4：Reliability Router 与受约束协同融合

## 目的与约束

Stage-3 证明消息会实质改变预测，但正常通信没有稳定优于同构无通信模型。本阶段检验一个更窄的问题：
能否让 Router 按样本选择“保留私有判断”还是“采用通信判断”，从而只在通信有益时使用它。

为避免 Router 退化成未声明的第三个分类器，实现施加以下结构约束：

1. 输入只包含冻结的无通信/通信系统状态、局部证据、消息邻接和状态改变量；
2. 输出只是在两套系统 class logits 与 unknown logits 之间的非负凸组合，权重和严格为 1；
3. 无通信和通信模型在 Router 训练期间均冻结；
4. Router 只用训练 Known 和按源样本分组隔离的伪未知训练、选轮；
5. 真实 Unknown 不参与训练、选轮、融合校准或阈值确定。

## 对照组

- `global`：所有样本共享一组学习权重；
- `single`：Known 分类与 Unknown 检测共用样本级权重；
- `dual`：Known 分类与 Unknown 检测分别使用样本级权重；
- `dual_uniform`：强制 `[0.5, 0.5]`，检验学习权重是否优于均匀组合；
- `dual_shuffled`：跨样本打乱路由权重，检验样本—权重对应关系是否重要；
- 固定无通信与固定通信：两端点基线；
- `dual_plus_three_mean`：把双路由 Unknown 证据与 Identity、Prototype、Reconstruction 三个独立证据等权融合。

每种完整规则均在自己的 Known validation 分数上做经验 CDF 校准，再在约 95% Known 接受率下评价，
避免把不同原始分数的同一个数值阈值进行不公平比较。

## 路由行为与结论

双路由的三种子平均权重（顺序为 `[无通信, 通信]`）为：

- Known 样本的 Known 路由：`[0.242, 0.758]`；
- Unknown 样本的 Known 路由：`[0.277, 0.723]`；
- Known 样本的 Unknown 路由：`[0.687, 0.313]`；
- Unknown 样本的 Unknown 路由：`[0.471, 0.529]`。

权重随样本类型发生变化，但这不足以证明有效路由：双路由没有超过全局/均匀权重，打乱权重也没有造成
一致的大幅退化。最强的 `dual_plus_three_mean` 与 Stage-2 四证据均值相比，AUROC 基本持平、OSCR
略升 0.001，但 Unknown Recall 下降 0.030、H-score 下降 0.021。因此 Stage-4 不通过净增益闸门，
保留为结构和负结果消融，不替代 Stage-2 当前最强方案。

训练期间伪未知验证 AUROC 约为 `0.997–0.999`，但真实 Unknown 明显更难，说明当前瓶颈首先是代理
未知的分布真实性，而非 Router 容量。下一阶段应开发 PUG-V2：更接近类流形边界的难伪未知、
leave-class-out episodic 代理验证，以及按代理任务而非单一合成分布选择协同策略。
